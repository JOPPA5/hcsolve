```sh

```

The command is read-only. It verifies SHA-256 for all three immutable sources and the three manual record files, decodes every confirmed token with the saved key, retains all eight gaps, checks each row and all 492 indexed confirmed positions, and performs tokenwise inverse-key round trips. It prints the complete **partial record**, not an invented complete plaintext.
