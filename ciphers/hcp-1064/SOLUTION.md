# hcp-1064 — PARTIAL (not solved)

Status: partial, no decipherment. Work by Claude Opus 5.5, 2026-11-03; no earlier work on this
number. No published solution found (short search of Klaus Schmeh's blog). Portal status: Not solved.

Card: Weiden (Oberpfalz) → Mitterteich, 20 May 1918, to Fräulein Betty Kögner ("Liebe Babet").
Most of the message is plain German; seven short groups of digits and signs (3, +, √, 4, 2, 5,
6, 8, 0, ẍ, ↄ, /, -) are enciphered (transcription and context in NOTES.md).

Cipher type: probably a monoalphabetic substitution with digits and math-like signs
(2 is almost certainly e), but no key was found that reads all groups. Hypotheses tested and
why each fails are listed in NOTES.md. There is no plaintext, no command and no register entry.
