## Key 1235 is already complete in the public delivery

The premise that `source/arcinsys/key1235-0001.jpg` was merely a cover was false. It is the actual alphabet and nomenclator table. The existing `NOTES.md` already recorded this.

The [official record](https://arcinsys.hessen.de/arcinsys/showArchivalDescriptionDetails.action?archivalDescriptionId=1472074) dates **HStAM 4 d 1235** to **ca. 1670**. Its public viewer explicitly links a [METS manifest](https://arcinsys.hessen.de/arcinsys/mets?detailid=v1472074). The current manifest lists **one DEFAULT image**, with the same image in DOWNLOAD and a separate thumbnail. A fresh download of that sole image is byte-for-byte identical to the existing source, SHA256 `22fc0dca99191d53e4f6d367a11226b9c40989d32869e6dd6ee109fceda04071`.

Thus no additional publicly delivered scan was missing locally. This does not prove that the physical archival item has no unphotographed verso or other material.

Visible table examples: A=41–44; D=53–56; G=65–68; Denmark=174; Sweden=192; **Duke of Holstein**=257 (not standalone Holstein); Alliance=301; Bischoff=303; General=320. The final visible word code is 363. The HCP 494 screening codes 601, 634 and 768 do not occur. Those target country readings remain secondary-gloss-based anchors, not assumed key values.

The earlier `compare_1677.py` already demonstrated a useful fit to the separate Dänemark 145 letter of 1677: 21/22 letter tokens, repeated Bauditz, and General320; its explicit 55 discrepancy remains. This is an existing result, not a new decipherment here, and does not transfer that alphabet to HCP 494.

## Key 255's 1676 endorsement: probable Celle lead

The unmodified native crop `key1235-full-2026-10-28/key255-endorsement-original.png` comes from `source/full/key255-0016.jpg`. Working transcription:

> Clavis mit H[errn?] [unread name] / zu Cleve. / und / hernach / mit Secretario Lincker / 1666. / Item / 1676. mit dem / **Herzog zu Cell[?]**

The first personal name and the ending of Cell remain uncertain. Parent and ending_alternative helper both found the last line compatible with Herzog zu Cell after seeing the hypothesis. This is **not a blind independent palaeographic review**. The reading is probable, not established fact. Georg Wilhelm is not written in the note; assigning that name requires contextual inference.

The useful consequence is a more specific search route: the key was probably reused with the duke at Celle in 1676. It does not establish that any Celle key has the target's enlarged word list.
