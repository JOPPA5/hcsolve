# Letter-trajectory CP-SAT experiment

This is a different exact known-plaintext representation from the character-array interval model. Each input position follows the complete physical column permutations through all three stages. Its final domain consists of every observed occurrence of the same letter; repeated letters are not assigned arbitrarily to a single occurrence. AllDifferent at every stage enforces bijective occurrence trajectories. Complete column intervals are packed by NoOverlap; allowed coordinate triples and Element connect each trajectory to its physical column start. Daily alignment, when supplied, is the readout rank of physical column zero.

Three independently generated blind fixtures are preserved in controls.json. The seven-letter widths2/3/4 fixture succeeds in0.022s, with complete physical re-encryption and every returned position trajectory independently checked. Both fresh65-letter fixtures at widths21/19/20 remain UNKNOWN after60seconds each, at daily ranks5 and7. Neither fixture provides planted keys, hints or a truth seed to the search. UNKNOWN is not UNSAT. No historical ciphertext was run and no key or plaintext is claimed.

Run `python3 batches/r364-coordinate-main/controls.py` from the repository root, with OR-Tools9.15.6755 available at /private/tmp/hcsolve-ortools. Dependencies/provenance are in ../r364-cpsat-main/SOURCES.md. This representation currently accepts fully known plaintext and no substitution errors; it has no unknown-filler or damaged-ciphertext branch. It therefore does not silently encompass the uncertain actual quote or original transcription. Small control success checks mechanics but is not an exhaustive model audit.
