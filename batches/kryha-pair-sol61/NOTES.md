# Evidence and limitations

The genuine coupled model recovered two fresh pairs completely (controls 0 and 2, 770/770 letters each), including a fresh negative-direction pair handled by exact ring reflection. Both standalone fourgram and fivegram refinements retain the exact full plaintexts. These are supplied-phase controls, not demonstrations of blind global phase identification. No true key or plaintext selects a profile seed, MASC winner, or refinement candidate.

Control 1 is an explicit non-exact result: 366/385 and 378/385, totaling 744/770. Every error is the input label swap Q↔X: 18 true X decoded Q and 8 true Q decoded X. Its entire output-ring permutation is recovered up global rotation, while 24/26 input slots match. The false prepared text has higher frozen fourgram score (1391.06 vs true 1329.63) and higher fivegram score (−801.366 vs true −816.909). Fivegram refinement therefore does not resolve this control. This preparation/model failure must not be converted into an exact success. Full raw texts and keys are preserved.

Control 0 uses 25 plaintext symbols, missing only W; the sole remaining unused input slot is forced by the permutation, so there is no free two-letter unused-slot swap in this control. Control 2 has three unused plaintext letters F/G/W; all 23 used input slots are recovered, while the unused three freely permute (six equivalent keys on these observations). Its 23/26 match to the planted input ring is therefore expected key ambiguity despite 770/770 plaintext recovery. The diagnostic comparison, including all controls, is in `control-diagnostics.json`. Independent reencryption and inverse checks are exact for every retained operative candidate.

The target pilot covers literal and fixed preferred complete 385-letter pairs, all 17 original schedule phases, with negative-direction reflection equivalence. Target outputs are candidates under a restrictive conditional family. The frozen scorer is Slovak-trained; the plaintext language and preparation are themselves conditional. A high score or exact reencryption alone is not a recovered natural plaintext. Failure cannot exclude the programmable 52-stop model, selective stepping, different rings/phases or message resets, open framing, remaining transcription errors, or even this restricted family under a probabilistic search and an imperfect frozen language model.

The physical source-preferred chronology is a possible 1 March 1944 sending interpretation for HCP351; recorded portal dates remain unchanged. No source delimiter establishes a 20-letter excluded header or 10-letter excluded footer. We use whole 385-letter texts and do not trim or invent source preparation.
