# Bounded source audit of Kryha message preparation

No inspected source establishes that SOSOL is a five-letter indicator, that Slovak Kryha preparation merged I/J, or which sentence marker this traffic used. The evidence gap remains explicit. Natural language after those five letters does not itself classify them.

## SSA NR2417: explicit German commercial procedure

[NR2417](https://cryptocellar.org/kryha/nr2417.pdf), Levine/Lewis, August1942, is a modern transcription of a primary memorandum. Local pages1,11,14,15 were read; pages1,14,15 visually checked. Page1 specifies one initial cipher letter marking component alignment, a final authentication letter two normal alphabet positions later, and an encrypted serial number enclosed by ZZ. It specifies J on a tab shared with a dash, used after every word, with an extra lever press. Page14 independently illustrates the resulting skipped active stop. Page15 examples contain J between words and X between phrases; it does not explicitly define X as a sentence terminator or prescribe replacing letterJ withI.

These are German commercial rules, not evidence that Madrid1944 adopted them. This message pair has first and last cipher letters S/S; the memo's authentication rule would demand S/U. Both transcription variants give the same failure (`nr2417-boundary-check.json`). This rejects only a direct application of that particular boundary rule.

## NSA machine descriptions

Printed185 and its full diagram/table were visually checked. Its demonstration alphabet lists I and J separately. Relevant analysis continuation printed188–204 was searched for indicator, separator, initial setting, and preparation language. No five-letter traffic prefix or I/J-merger instruction was found in this inspected section. A demonstration alphabet is not evidence of the target's preparation practice.

The official [NSA Q.E.D. article](https://www.nsa.gov/portals/75/documents/news-features/declassified-documents/tech-journals/qed.pdf), Callimahos,1973, was readable through the web tool. Appendix PDFpage8 describes ordinary stepping and lists I/J separately; text searches found no indicator or separator rule. This source treats an early1933 test, not Madrid1944 practice. The older local file named qed.pdf remains an access-denied HTML artifact and was not used as a PDF; it was not altered.

## Slovak archival research: bounded contextual evidence

Antal/Grošek/Zajac, [Vojenská história24(3),2020,95–108](https://www.vhu.sk/data/att/178/20273.07b25c.pdf), original archival research. Relevant local scan pages97,99–101,103 were visually read. The underlying archival manuals themselves are not reproduced there and were not inspected in this task.

Page100 footnote49 reports that a cipher sent to Helsinki in1943 was called SVERK, later identified as Kryha, citing SNA MZV box41,12/dôv1943. This is evidence for a five-letter cipher NAME, not for an initial five-letter message indicator and not for SOSOL. Page100 footnote55 reports a1941 economy change from numbers written in words to Roman numeral letters, citing MZV28.002/1941; this cannot be transferred unchanged to1944 machine preparation. Page101 explains that file descriptions had to reformulate message contents, so file labels cannot be treated as literal plaintext cribs. None of these inspected pages supplies the missing I/J or sentence-marker rule.

The machine procedure would have to be recalibrated independently if that rule were introduced.
