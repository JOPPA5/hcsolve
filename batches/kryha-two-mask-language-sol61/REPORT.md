# Main audit note: superseded pooled-histogram heuristic

The original `run-profile.py` subtracts constant `K[0]` from message B before pooling both messages in a histogram later shifted only by message A's cumulative displacement. This is incorrect for that pooled representation: it must subtract `K[i % 23]`. Constant `K[0]` is appropriate when message B is projected with its own physical displacement, as in `project.py` and the independently verified full-body codecs. Therefore the earlier profile shortlist is a mismatched heuristic; its failure or rank cannot be interpreted as evidence against the target. The exact path counts, physical witnesses and full-body candidate reencryption checks are unaffected. Corrected profile calibration and searches are preserved separately in `batches/kryha-two-mask-reset-sol61/`; independent exhaustive language scoring using both physical paths is in `batches/kryha-two-mask-refine-sol61/`. Original profile artifacts are retained to make the earlier error auditable.
