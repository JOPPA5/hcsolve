# Public 373 comma-only markers with unknown mixed rings

This is public known-plaintext context work for unresolved 374, not a new plaintext solution of already published 373. A prior-scope check in `SCOPE-AUDIT.md` identified a preparation gap: earlier comma-only J/X tests used fixed 350 alphabet rings, whereas unknown-ring tests used concatenation or a marker at every word boundary. This batch keeps every source word and inserts a marker only at the single literal comma after CELULOZIEK in the prefix before `6.000`.

Eight preparations combine USTREDNI versus source USTRENI, natural J versus I, and emitted comma J versus X. Natural J→I is applied to the original letters before inserting the marker, so an inserted delimiter J remains J. Each prefix has 94 or 93 emitted letters. There are no Q-name hypotheses, guessed words, extra invisible presses, or all-word-boundary markers.

The model searches arbitrary independent input/output alphabet permutations and a cyclic displacement sequence of period 2..52, with ordinary consecutive presses and the known full-cycle displacement 179 modulo 26. Every ciphertext offset 0..25 is explicit, including five-symbol framing and a possible additional initial delimiter. Absolute ciphertext glyphs 53 L/I and 90 E/A are changed only in working variants before slicing. The complete bound is 8 × 26 × 4 × 51 = 42,432 cases. The priority pass covers natural-I/comma-J preparations, offsets 5/6, periods 16..30; the remainder follows a fixed declared order and skips those identifiers already recorded.

Exact field elimination and CRT reduce each linear family. The previously independently audited vector enumerator closes active dimensions GF(2)<=5, GF(13)<=4, product<=913,952. Every UNSAT enumeration checks the full product count. Larger active families fall back to the existing observed-ring SMT model with a 1,000 ms timeout and retain UNKNOWN on timeout. The generic K model is a necessary relaxation of the physical stop-mask model, not a physical key reconstruction.

Before actual cases, two fresh 94/93-letter controls use arbitrary mixed alphabet rings, random physical wheel masks with periods 23/20, unknown starting phase, and framed offsets 5/6. Two independent physical encoders agree on the full ciphertext: literal adjacent-wheel walking and absolute unwrapped coordinates. The solver receives only plaintext and each candidate ciphertext slice, and searches all 26 offsets × 51 periods. Each control uniquely accepts one offset/period pair, with 1,325 UNSAT and one SAT, and recovered permutations pass independent complete-prefix re-encryption and inverse checks. No truth ring, stop list, phase, offset, or period is seeded into the solver. Control inputs, truths, and all scan results are retained separately.

Case evidence is append-only `results.jsonl`, identified by preparation index, offset, glyph53, glyph90, and period. `input.json` records exact preparations, source raw prefix, bounds, and source hashes. All **42,432 cases are exact UNSAT**, with zero SAT and zero UNKNOWN. Every expected identifier occurs exactly once. This closes only the declared comma-only preparations, offsets, glyph alternatives, ordinary press rule, period range, fixed positive 179-cycle model, and arbitrary-ring displacement relaxation. Final counts are in `summary.json`. A SAT retains both rings, displacement sequence, exact prefix verification and full remaining-373 context decode for further assessment; it would not by itself establish a physical key or transferable 374 solution.

The source collation and all earlier negative results remain unchanged. No 373 cipher directory, register entry, marker, or new plaintext claim is created. Root owns the unresolved 374 shared documents.
