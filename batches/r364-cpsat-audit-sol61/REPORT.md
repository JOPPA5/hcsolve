Exhaustive enumeration directly constructs all allowed physical key triples via itertools.permutations and filters their alignment ranks, then composes explicit source-index permutations. It never calls the model's encoder or decoder. A one-position unknown filler appears at exactly one outputposition under any bijective key triple; independently choosing its value equal to that observed ciphertext character is its exact optimal Hamming assignment over all26letters. Allotherpositions are fixed. This analytically exhausts filler values while directly enumerating every allowed key triple. Thus minimum mismatch and witness existence at each error bound are exact, not sampled.348,192key triples were evaluated across the216cases.

CP-SAT receives no known keys, hints or truth seed. Returned key tuples must belong to the independently enumerated admissible set. Their entire predicted ciphertext must equal independent encryption; independent inversion must recover the inferred fulltemplatecompletion. The predicted ciphertext is allowed to differ from the deliberately damaged observed ciphertext only within the disclosed error budget. These checks do not confuse equality against damaged input with equality against the reconstructed undamaged message.

The NoOverlap encoding is also structurally consistent for this domain: positive-length column intervals totalNinside[0,N], hence nonoverlap forces complete output coverage; each chosen interval copies a complete physical column through Element. The tested daily conditions compare physical interval order. Enumerationagreement covers both positive and negative cases, which is stronger than checking planted keys alone. It is still bounded validation at lengths7/11, oneunknownfiller and0/1errors, not a formalproof for every possible input or a performance prediction for65letters/21/19/20.
