# Restricted standard-alphabet Kryha scout

Two fresh385-letter held-out controls were recovered exactly with unknown physical mask, active count, starting hole and relative alphabet offset, under the explicitly restricted condition of standard A–Z input/output rings. Actual350/351 original and source-preferred whole readings remain incoherent. There is no unrestricted Kryha solution or family exclusion.

## Model and search

Input positions are standard A–Z; output position of ciphertext c is c+offset mod26. For displacement d from the real52-hole wheel, plaintext is c+offset-d mod26. Offset ranges0–25, active count20–30, starting hole0–51. Every physical mask is selected in positive cyclic hole order; complete stop cycle sums179. Exactly one ordinary press follows each letter. Selective-J extra presses, negative effective displacement, nonstandard alphabets, stop counts outside20–30 and other wheel versions are outside this branch. No historical adoption of these standard alphabets is established.

The structural beam is the previously independently checked real-hole language beam. Width64 per depth; all52starts are explored for each of11counts×26offsets. Models2/3/4/5 and weights0.1/0.15/0.4/0.8 are frozen TRAIN-only as in the parent mask batch. Four best full masks are retained across starts per(count,offset), yielding1144complete key/text candidates per input. Models load once. Truncation means this is a scout, not exhaustive mask enumeration or an exclusion proof.

## Reproduce

```sh
python3 batches/kryha-mask-sol61/ring-calibration/standard-rings/prepare.py
clang++ -O3 -std=c++17 batches/kryha-mask-sol61/ring-calibration/standard-rings/scout.cpp -o batches/kryha-mask-sol61/ring-calibration/standard-rings/scout
python3 batches/kryha-mask-sol61/ring-calibration/standard-rings/run.py controls
python3 batches/kryha-mask-sol61/ring-calibration/standard-rings/prepare-targets.py
python3 batches/kryha-mask-sol61/ring-calibration/standard-rings/run.py targets
python3 batches/kryha-mask-sol61/ring-calibration/standard-rings/run.py preferred
python3 batches/kryha-mask-sol61/ring-calibration/standard-rings/check.py
```

Control ciphertexts are generated by prepare.py. Explicit target inputs/provenance are saved as target*.txt and targets.json and preserved by the control generator. Runs overwrite only their own branch TSVs/logs; archive outputs before changed-parameter comparisons. No source cipher, watcher, reviewer, marker or register entry modified.
